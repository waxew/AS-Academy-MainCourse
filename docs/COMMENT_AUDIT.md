# MainCourse Comment Audit

## وضعیت

این سند ثبت می‌کند که توضیحات ساختاری برای فایل‌های MainCourse چگونه اعمال می‌شوند.

## 1. بررسی فایل‌ها

- تمام مسیرهای `courses/*` باید دارای README یا manifest توضیح‌دهنده باشند.
- فایل‌های metadata باید دارای توضیح هدف، مالکیت و ارتباط با Core باشند.
- تغییرات محتوایی باید دلیل تغییر و اثر آن روی Runtime Content Update مشخص شود.

## 2. استاندارد توضیح Metadata

هر manifest باید توضیح دهد:

- شناسه پایدار Course
- نسخه محتوا
- وابستگی به Core
- سطح آموزشی
- مالک این داده

## 3. استاندارد توضیح Lesson

هر Lesson باید شامل:

- هدف یادگیری
- پیش‌نیاز
- خروجی مورد انتظار
- تمرین مرتبط
- معیار پذیرش

## 4. وضعیت فعلی

ساختار مستندسازی آماده است. مرحله بعدی اعمال توضیحات داخل manifestها و فایل‌های محتوایی هر Course است.
