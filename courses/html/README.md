# HTML Course Package

این پوشه منبع واحد محتوای آموزشی HTML در AS Academy است.

- Source of Truth: `AS-Academy-MainCourse/courses/html/course`
- Course app/repository: `AS-Academy-HTML`
- Shared UI: `AS-Academy-MainUi`
- Shared engine/runtime: `AS-Academy-Core`

تمام درس‌ها، فصل‌ها، تمرین‌ها، Quizها، آزمون‌ها، پروژه‌ها، Capstone، Glossary، منابع و metadata آموزشی HTML از اینجا مدیریت می‌شوند. Course App محتوا را از این مسیر دریافت می‌کند و نباید fork مستقل محتوا داشته باشد.

محتوای فارسی این دوره با جمع‌بندی و بازنویسی آموزشی از مراجع معتبر تهیه شده و کپی مستقیم از منابع نیست. محورهای مرجع شامل WHATWG HTML Living Standard، MDN Web Docs، web.dev، W3Schools و منابع آموزشی فارسی مانند راکت و سبزلرن است.
