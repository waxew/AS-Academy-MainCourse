# منابع فارسی و مراجع فنی — فریم‌ورک‌های Frontend

آخرین بازبینی: 2026-09-01

این فایل فهرست منابع برای تحقیق و تکمیل محتوای فارسی Course است. متن منابع دارای حق نشر نباید عیناً کپی شود؛ محتوا باید با نگارش مستقل AS Academy، مثال‌های اختصاصی، تمرین و آزمون تولید شود. برای صحت API و رفتار Frameworkها، مستندات رسمی منبع نهایی هستند.

## منابع آموزشی فارسی بررسی‌شده

### پلتفرم‌های جامع
- فرادرس — https://faradars.org — دوره‌های فارسی React، Vue، Angular، JavaScript/TypeScript و مباحث وب.
- مکتب‌خونه — https://maktabkhooneh.org — دوره‌های فارسی برنامه‌نویسی وب و برخی Frameworkهای Frontend.
- راکت — https://roocket.ir — آموزش‌های فارسی توسعه وب، React، Vue، Nuxt و اکوسیستم Frontend.
- سبزلرن — https://sabzlearn.ir — آموزش‌های فارسی React، Next.js و توسعه Frontend.

### React و State Management
- جست‌وجوی دوره‌های React فارسی در فرادرس، راکت، سبزلرن و مکتب‌خونه.
- مباحث مورد استخراج آموزشی: Component، JSX، Props، State، Hooks، Context، Routing، API، Redux Toolkit، معماری و Performance.

### Next.js
- منابع فارسی سبزلرن و سایر پلتفرم‌های فارسی برای مبانی Next.js.
- موضوعات الزامی: App Router، Server/Client Components، SSR، SSG، Cache/Revalidation، Route Handlers، Middleware، SEO و Deployment.

### Vue و Nuxt
- دوره‌های Vue فارسی در فرادرس، راکت و مکتب‌خونه.
- آموزش‌های Nuxt فارسی در راکت و منابع فارسی وب.
- موضوعات الزامی: Composition API، Vue Router، Pinia، Nuxt Routing، Data Fetching، Server Routes، SSR و SSG.

### Angular
- دوره‌های فارسی Angular در فرادرس و مکتب‌خونه و منابع فارسی وب.
- موضوعات الزامی: Components، DI، Router، Reactive Forms، HttpClient، Signals، Standalone Components، Testing و معماری سازمانی.

### Svelte و SvelteKit
- منابع فارسی این حوزه نسبت به React/Vue محدودترند؛ برای پوشش کامل، محتوای فارسی AS Academy باید با اتکا به مستندات رسمی و نگارش آموزشی مستقل تکمیل شود.
- موضوعات الزامی: Svelte reactivity، runes/current syntax، stores/context، transitions و SvelteKit routing/load/form actions/SSR/prerender.

### Design System و Component Library
- منابع فارسی طراحی سیستم، Storybook، UI Component Architecture و Accessibility به‌عنوان منابع مکمل بررسی می‌شوند.
- آموزش تخصصی AS Academy باید Design Token، API Design، Headless UI، Storybook، RTL، Accessibility، Packaging، Versioning و Visual Regression را یکپارچه کند.

## روش استفاده در Course
1. منبع فارسی برای نحوه توضیح قابل‌فهم و پوشش نیاز فارسی‌زبان بررسی می‌شود.
2. ادعاها و APIهای فنی با مستندات رسمی تطبیق داده می‌شوند.
3. متن نهایی از صفر و با نگارش فارسی AS Academy تولید می‌شود.
4. مثال‌ها، تمرین‌ها، Quizها و پروژه‌ها اختصاصی Course هستند.
5. هر مطلب وابسته به نسخه باید در بازبینی‌های بعدی دوباره با مستندات رسمی کنترل شود.

## خلأهای محتوایی که AS Academy باید پوشش دهد
- مقایسه عمیق Frameworkها در یک Course واحد
- SSR/SSG/ISR/Streaming به‌صورت مستقل از Framework
- State taxonomy و انتخاب ابزار مناسب
- فرم و Validation چندFrameworkی
- Design System و Component Library از طراحی تا انتشار Package
- Accessibility و RTL در سطح Production
- Security و Performance
- Testing چندلایه
- Monorepo/Micro Frontend و معماری Enterprise
- پروژه Capstone واقعی با استاندارد Production
