# Branding / MainUi Integration

این Course از Design System مشترک `AS-Academy-MainUi` استفاده می‌کند.

- UI فارسی و RTL
- Code Block و Terminal به‌صورت LTR
- سطح‌ها، فصل‌ها، Progress، Search، Quiz، Exercise و Project از Componentهای مشترک MainUi/Core استفاده کنند.
- Course نباید UI اختصاصی fork شده ایجاد کند؛ فقط metadata و assetهای هویتی مخصوص Course در این پوشه قرار می‌گیرند.
