# دوره جامع فریم‌ورک‌های Frontend

مسیر: طراحی و توسعه وب‌سایت ← فریم‌ورک‌های Frontend

این Course برای آموزش فارسی از مبانی تا سطح تخصصی طراحی شده و محتوای آن باید در رابط مشترک `AS-Academy-MainUi` نمایش داده شود. هدف، آموزش صرفاً نظری نیست؛ هر فصل باید با توضیح مفهومی، مثال، تمرین، Quiz و پروژه عملی تکمیل شود.

## سطح ۱ — مبانی

### 1. پیش‌نیازها و معماری Frontend مدرن
- مرور HTML، CSS، JavaScript و TypeScript موردنیاز
- Node.js، npm، pnpm و مدیریت Package
- Bundler و Build Tool؛ Vite و مفاهیم Build
- SPA، MPA و تفاوت آن‌ها
- CSR، SSR، SSG، ISR و Hydration
- Component-Based Architecture
- Virtual DOM، DOM و Reactive UI
- Routing و Client-side Navigation
- State و چرخه داده
- REST، GraphQL و اتصال UI به Backend
- Environment Variable و تنظیم محیط Development/Production
- Git، DevTools و Debugging

### 2. انتخاب Framework مناسب
- مقایسه React، Vue، Angular و Svelte
- مقایسه Next.js، Nuxt و SvelteKit
- معیارهای انتخاب برای فروشگاه، داشبورد، SaaS، وبلاگ و پروژه سازمانی
- Ecosystem، Community، Hiring، Performance و Maintainability
