# Lessons

درس‌های فارسی این Course در این پوشه نگهداری می‌شوند. هر درس باید Stable ID داشته باشد و به chapterId و levelId متصل شود.

الگوی اجباری درس: هدف یادگیری، پیش‌نیاز، توضیح مفصل فارسی، واژگان، مثال کد، تحلیل، خطاهای رایج، تمرین هدایت‌شده، تمرین مستقل، Quiz reference، پروژه/Challenge و منابع بازبینی‌شده.
