# ذخیره‌سازی اطلاعات و دیتابیس / مفاهیم پایه

بسته آموزشی مستقل «مفاهیم پایه ذخیره‌سازی اطلاعات و دیتابیس» برای AS Academy.

این دوره با معماری MainCourse + MainUi + Core ساخته شده و از مبانی تا تخصصی پیش می‌رود. هدف نهایی این است که هنرجو بتواند مدل داده و معماری ذخیره‌سازی یک پروژه واقعی را تحلیل و انتخاب کند.

محتوای اصلی در `course/` قرار می‌گیرد و شامل درس، تمرین، آزمون، پروژه، واژه‌نامه و منابع است.
