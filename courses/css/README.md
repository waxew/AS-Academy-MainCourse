# AS Academy — CSS

این پوشه منبع مرکزی محتوای دوره CSS برای AS Academy است.

- زبان محتوا: فارسی
- سطح‌بندی: مبانی، مقدماتی، پیشرفته، تخصصی
- UI: از AS-Academy-MainUi
- منطق مشترک: از as-academy-core
- اپ اختصاصی: AS-Academy-CSS

محتوا باید از طریق Content/Course Engine برنامه فراخوانی شود؛ اپ CSS نباید نسخه مستقل و تکراری درس‌ها را نگهداری کند.
