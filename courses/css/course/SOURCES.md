# منابع تدوین دوره CSS

## منابع مرجع اصلی
- MDN Web Docs — CSS Guides & Reference
- web.dev — Learn CSS
- W3C CSS Working Group — CSS Snapshot و specificationهای ماژولار

## منابع فارسی
برای تدوین فارسی، آموزش‌ها و مثال‌های فارسی معتبر از پلتفرم‌های آموزشی و وب فارسی به‌عنوان منبع تکمیلی بررسی می‌شوند. محتوا عیناً کپی نمی‌شود؛ ساختار درس‌ها تألیفی است و صحت فنی با مستندات اصلی بالا تطبیق داده می‌شود.

## معیار به‌روزرسانی
ویژگی‌های جدید CSS بر اساس وضعیت استاندارد، پشتیبانی مرورگر و suitability برای production طبقه‌بندی می‌شوند. قابلیت‌های آزمایشی باید صریحاً با برچسب Experimental/Progressive Enhancement معرفی شوند.
