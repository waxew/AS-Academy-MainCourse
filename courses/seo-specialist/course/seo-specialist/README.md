# پروژه: SEO تخصصی

این پوشه محتوای تفصیلی مسیر «SEO تخصصی» است و باید توسط Course Reader مشترک AS Academy نمایش داده شود.

## هدف دوره
هنرجو از نقطه صفر با سازوکار موتورهای جستجو شروع می‌کند و در پایان قادر است برای یک وب‌سایت واقعی فارسی Technical Audit انجام دهد، Keyword Strategy و Content Architecture طراحی کند، مشکلات Crawl/Index/Rendering را تشخیص دهد، داده‌های GSC/GA4 را تحلیل کند و یک برنامه رشد Organic قابل اندازه‌گیری ارائه دهد.

## روش آموزش
هر موضوع با الگوی ثابت ارائه می‌شود: «تعریف ساده → مفهوم فنی → مثال واقعی → روش اجرا → ابزار → خطاهای رایج → چک‌لیست → تمرین → آزمون → پروژه». محتوا نباید صرفاً فهرست اصطلاحات باشد.

## مسیر یادگیری
1. مبانی: SEO، SERP، Crawl، Render، Index، Rank، Intent و زیرساخت وب.
2. مقدماتی: Keyword Research، On-page، Search Console و ساختار محتوا.
3. متوسط: Technical SEO، Schema، Core Web Vitals، معماری و Index Management.
4. پیشرفته: Semantic/Entity SEO، Link Building، JavaScript SEO، Ecommerce/Local/International.
5. تخصصی: Log Analysis، Enterprise/Programmatic SEO، Analytics، Migration/Recovery، AI Search/GEO و Automation.
6. پروژه‌محور: Audit و اجرای استراتژی واقعی روی یک سایت فارسی.

## استاندارد محتوایی
- زبان اصلی: فارسی؛ اصطلاح انگلیسی در اولین استفاده کنار معادل فارسی آورده شود.
- ادعاهای مربوط به Google با مستندات رسمی Google Search Central تطبیق داده شوند.
- تکنیک‌های پرریسک/Spam با برچسب روشن و توضیح پیامد آموزش داده شوند، نه به‌عنوان Best Practice.
- درس‌های AI Search با تغییر مستندات رسمی قابل به‌روزرسانی مستقل باشند.
- مثال‌ها شامل سایت محتوایی، شرکتی، فروشگاهی و JavaScript-based باشند.
