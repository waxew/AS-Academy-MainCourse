# سطح ۲ — SEO مقدماتی

## Keyword Research
تحقیق کلمه کلیدی باید از مسئله و نیاز کاربر شروع شود، نه صرفاً عدد Search Volume. Seed Topicها را از محصول، مشتری، Search Console، SERP، رقبا و پرسش‌های واقعی استخراج کنید. سپس Keywordها را بر اساس Intent، Topic، Funnel Stage، Business Value و نوع صفحه گروه‌بندی کنید.

### Keyword Mapping
برای هر Cluster یک URL هدف تعریف کنید. چند URL با Intent یکسان می‌توانند موجب Cannibalization شوند. Mapping کمک می‌کند مشخص شود کدام موضوع نیاز به Landing Page، Category، Product، Article، Guide یا FAQ دارد.

## On-page SEO
### Title
عنوان باید موضوع و ارزش صفحه را روشن کند و با Intent هماهنگ باشد. Keyword stuffing و عنوان گمراه‌کننده ممنوع است.
### Meta Description
سیگنال مستقیم تضمین‌شده برای رتبه نیست؛ اما متن مناسب می‌تواند فهم نتیجه و CTR را بهبود دهد. Google ممکن است Snippet متفاوتی انتخاب کند.
### Headings
H1 تا H6 برای ساختار معنایی محتوا استفاده شوند، نه صرفاً تغییر اندازه فونت.
### URL
کوتاه، پایدار، قابل فهم و بدون پارامترهای غیرضروری باشد. تغییر URL موجود فقط برای زیبایی معمولاً توجیه ندارد.
### Internal Linking
صفحات مهم باید از مسیرهای منطقی و با Anchor مرتبط لینک بگیرند. Orphan Pageها باید شناسایی شوند.
### Image SEO
نام و Context مناسب، alt توصیفی در موارد لازم، ابعاد صحیح، فرمت و Compression مناسب، Lazy Loading صحیح و جلوگیری از Layout Shift بررسی شود.

## Search Console از صفر
1. ساخت/تأیید Property.
2. ثبت Sitemap.
3. بررسی URL Inspection.
4. تحلیل Queries، Pages، Countries و Devices در Performance.
5. بررسی Indexing و علت Excluded شدن URLها.
6. بررسی Enhancements و Structured Data.
7. بررسی Manual Actions و Security Issues.

## تمرین پروژه‌ای
برای یک کسب‌وکار فرضی فروش لپ‌تاپ، حداقل ۳۰ Keyword جمع‌آوری کنید؛ آن‌ها را Cluster کنید؛ Intent و URL Type تعیین کنید و یک Site Map محتوایی اولیه بسازید. سپس برای یک Category و یک Article، Title، Meta، H1، Outline و Internal Links طراحی کنید.
