# سطح ۵ — SEO تخصصی

## Log File Analysis
Server Log نشان می‌دهد Bot واقعاً چه URLهایی را درخواست کرده است. داده‌ها را بر اساس User-Agent معتبر، URL، Status، Timestamp و Response Size تحلیل کنید. اهداف: یافتن URLهای پرتکرار، صفحات مهم کم‌خزش، 3xx/4xx/5xx برای Bot، Trapها و Waste.

## Enterprise و Programmatic SEO
در سایت‌های بزرگ، Template Governance، Ownership، Release Process، Monitoring، SEO QA و Prioritization بر اساس Impact/Cost ضروری‌اند. صفحات Programmatic فقط وقتی ارزشمندند که هر صفحه پاسخ واقعی و متمایز به Intent بدهد؛ Quality Gate، Indexation Rules و Sampling Audit الزامی است.

## SEO Analytics
KPIها را به Visibility، Acquisition و Business Outcome تقسیم کنید. CTR را در Context Query/Position/Brand بررسی کنید. Forecast باید Baseline، Seasonality، CTR Curve، Scenario و عدم قطعیت را لحاظ کند.

## Migration و Recovery
پیش از مهاجرت URL Inventory، Mapping، Benchmark، Crawl و Redirect Plan بسازید. در Launch وضعیت status/canonical/robots/noindex/sitemap/internal links و پس از آن logs، GSC، traffic و redirect errors را کنترل کنید. افت Organic را بر اساس Date، Query، Page، Device، Country و Search Appearance Segment کنید و Deployment، Indexation، Manual Action، Security، Seasonality، SERP Change و Algorithm Update را بررسی کنید.

## AI Search و GEO
برای حضور در AI features، پایه‌های SEO همچنان ضروری‌اند: Crawl/Index صحیح، محتوای مفید و قابل اتکا و تجربه فنی مناسب. محتوای روشن، Entityهای مشخص، شواهد، داده دست اول و ساختار قابل فهم مفیدند؛ هیچ Markup یا فایل جادویی تضمین‌کننده Citation در پاسخ AI نیست.

## AI-assisted SEO و Automation
AI برای Classification، Clustering، استخراج Pattern، Draft اولیه و Automation مفید است؛ اما Fact، Intent، Original Value، Spam Risk و Brand Voice باید بازبینی شوند. Pipeline نمونه: GSC API + Crawl Data → تشخیص صفحات Impression بالا/CTR پایین → بررسی Title/Intent → Backlog. Rate Limit، Error Handling، Logging و Human Review ضروری‌اند.

## پروژه تخصصی
برای یک سایت حداقل ۱۰۰۰ URL، Technical Audit، Indexation Model، Content Gap، Internal Link Graph، Log Analysis، CWV، Backlink Profile و KPI Dashboard تهیه کنید و Backlog را با P0/P1/P2 اولویت‌بندی کنید.
