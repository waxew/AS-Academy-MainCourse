# منابع و مراجع دوره SEO تخصصی

تاریخ بازبینی: 2026-09-01

## منابع مرجع اصلی
مبنای صحت فنی دوره، مستندات رسمی Google Search Central و Search Console است. موضوعات اصلی مورد استفاده:

- SEO Starter / Search Essentials و مستندات How Search Works
- Crawling & Indexing: robots.txt، Sitemap، Canonicalization، Status Codes و Crawl Budget
- JavaScript SEO: Crawling → Rendering → Indexing و Best Practiceهای JS-powered sites
- Structured Data و Rich Results: JSON-LD، Eligibility و General Guidelines
- Core Web Vitals و Page Experience
- Google Search Console: Performance، Indexing، URL Inspection، Enhancements و Manual Actions
- AI features and your website: AI Overviews و AI Mode؛ طبق راهنمای رسمی Google، SEO Best Practices موجود همچنان معتبر است و Requirement فنی ویژه و جداگانه‌ای برای حضور در این قابلیت‌ها وجود ندارد.

## منابع فارسی برای مطالعه تکمیلی و واژگان
برای پوشش فارسی، آموزش‌ها و مقالات به‌روز وب فارسی درباره موضوعات زیر به‌عنوان منابع تکمیلی بررسی می‌شوند: مبانی SEO، تحقیق کلمات کلیدی، Search Intent، Search Console، Technical SEO، Core Web Vitals، Schema، SEO فروشگاهی، لینک‌سازی، SEO وردپرس و تحلیل رقبا. محتوای Course بازنویسی آموزشی و مستقل است و متن منابع کپی نمی‌شود.

### معیار پذیرش منبع فارسی
1. نویسنده/ناشر مشخص و سابقه آموزشی قابل بررسی داشته باشد.
2. تاریخ محتوا و امکان منسوخ‌شدن تکنیک بررسی شود.
3. ادعاهای مربوط به Google با Search Central تطبیق داده شوند.
4. تکنیک‌های Gray/Black Hat به‌عنوان Best Practice وارد درس نشوند.
5. مثال فارسی برای درک هنرجو استفاده شود ولی قاعده فنی از مستند رسمی استخراج شود.

## سیاست به‌روزرسانی
موضوعات AI Search، Structured Data، Core Web Vitals، Search Console، Spam Policies و Search Appearance باید در نسخه‌های بعدی Course مستقل از مبانی قابل به‌روزرسانی باشند، چون این بخش‌ها سریع‌تر تغییر می‌کنند.
