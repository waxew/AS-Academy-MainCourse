# SEO تخصصی — AS Academy

این Course Package مسیر جامع آموزش SEO را به زبان فارسی از مبانی تا سطح تخصصی و پروژه‌محور ارائه می‌کند.

## ساختار

- `course/manifest.json`: متادیتای دوره
- `course/levels.json`: سطوح مبانی، مقدماتی، متوسط، پیشرفته، تخصصی و پروژه‌محور
- `course/chapters.json`: نقشه فصل‌ها
- `course/seo-specialist/`: پوشه محتوای تفصیلی پروژه «SEO تخصصی»
- `course/exercises/`: تمرین‌های عملی
- `course/assessment/`: آزمون و ارزیابی
- `course/projects/`: پروژه‌های واقعی و Capstone
- `course/references/`: منابع فارسی و مستندات مرجع

محتوا با قرارداد `AS-Academy-MainCourse` سازگار است و برای نمایش توسط Design System مشترک `AS-Academy-MainUi` طراحی شده است.
