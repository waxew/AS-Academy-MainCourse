# دوره جامع اینترنت اشیا (IoT)

این پوشه Course Package مرجع اینترنت اشیا برای AS Academy است و مطابق قرارداد AS-Academy-MainCourse و AS-Academy-MainUi ساخته شده است.

## مسیر یادگیری
مبانی → مقدماتی → متوسط → پیشرفته → تخصصی → پروژه‌محور

## پوشش
معماری IoT، الکترونیک، ESP32/Arduino/Raspberry Pi، سنسور و عملگر، UART/I2C/SPI/RS485/CAN، TCP/IP/Wi-Fi/BLE/Zigbee/Thread، MQTT/HTTP/WebSocket/CoAP، Backend/API، Time-Series DB، Node-RED/Grafana، LoRaWAN/NB-IoT/LTE-M، امنیت، OTA، Edge، Low-Power، Reliability، IIoT/OPC UA، Matter، Cloud، TinyML و PCB/Productization.

## روش آموزشی
هر فصل برای استفاده داخل نرم‌افزار طراحی شده است: توضیح فارسی، مثال، نکته مهندسی، هشدار، تمرین و پروژه. متن‌های آموزشی تألیفی و مبتنی بر جمع‌بندی منابع هستند؛ متن منابع بیرونی کپی نشده است.

## منابع پژوهشی فارسی و تکمیلی
فهرست منابع و راهنمای ارزیابی آن‌ها در `sources-fa.md` نگهداری می‌شود. منابع فارسی برای یادگیری تکمیلی استفاده می‌شوند و مستندات رسمی سازندگان/استانداردها مرجع نهایی جزئیات فنی نسخه‌محور هستند.
