# C# Course Package

این پوشه منبع واحد محتوای آموزشی C# در AS Academy است.

- Source of Truth: `AS-Academy-MainCourse/courses/csharp/course`
- App shell: `AS-Academy-Csharp`
- Shared UI: `AS-Academy-MainUi`
- Shared engine: `AS-Academy-Core`

از زمان این مهاجرت، درس، فصل، تمرین، Quiz، آزمون، پروژه، Capstone، Glossary و Branding دوره C# باید در همین پوشه تغییر کند و App دوره فقط آن را بسته‌بندی/مصرف کند.
