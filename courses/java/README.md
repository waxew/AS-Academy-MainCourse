# Java Course Package

این پوشه منبع واحد محتوای آموزشی Java در AS Academy است.

- Source of Truth: `AS-Academy-MainCourse/courses/java/course`
- App shell: `AS-Academy-Java`
- Shared UI: `AS-Academy-MainUi`
- Shared engine: `AS-Academy-Core`

از زمان این مهاجرت، درس، فصل، تمرین، Quiz، آزمون، پروژه، Capstone، Glossary و Branding دوره Java باید در همین پوشه تغییر کند و App دوره فقط آن را بسته‌بندی/مصرف کند.

نسخه موجود در `AS-Academy-Java/course` تا پایان تثبیت مهاجرت فقط Snapshot سازگاری است و نباید محل توسعه محتوای جدید باشد.
