# Python Course Package

این پوشه منبع واحد محتوای آموزشی Python در AS Academy است.

- Source of Truth: `AS-Academy-MainCourse/courses/python/course`
- Course app/repository: `AS-Academy-Python`
- Shared UI: `AS-Academy-MainUi`
- Shared engine/runtime: `AS-Academy-Core`

درس، فصل، تمرین، Quiz، آزمون، پروژه، Capstone، Glossary، Learning Map، Outcomes و metadata آموزشی Python از اینجا مدیریت می‌شوند.
