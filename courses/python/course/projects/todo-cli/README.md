# پروژه مرحله‌ای — Todo CLI

هدف: تبدیل مفاهیم مقدماتی به یک برنامه چندفایلی که داده را بین اجراها حفظ می‌کند.

## معماری پیشنهادی
```text
todo/
├── app.py
├── models.py
├── storage.py
└── tasks.json
```

## قابلیت‌ها
1. افزودن کار
2. فهرست کارها
3. علامت انجام‌شده
4. حذف
5. ذخیره و بارگذاری JSON
6. مدیریت فایل خراب یا ناموجود
7. ثبت رخدادهای مهم با logging

## مدل Task
هر task حداقل `id`، `title` و `done` دارد.

## قوانین
- title خالی پذیرفته نشود.
- id تکراری ایجاد نشود.
- خطای فایل باعث crash برنامه نشود.
- منطق JSON فقط در storage قرار گیرد.
- UI خط فرمان مستقیماً جزئیات فایل را مدیریت نکند.

## آزمون دستی
- اجرای اول بدون فایل
- افزودن سه task
- بستن و اجرای دوباره
- تکمیل یک task
- حذف id ناموجود
- قرار دادن JSON خراب و بررسی رفتار برنامه

## توسعه اختیاری
priority، due date، search و filter را اضافه کنید.
