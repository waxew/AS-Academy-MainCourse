# پروژه مرحله‌ای — مدیریت نمرات

هدف: هنرجو مفاهیم مبانی Python را در یک برنامه واقعی کوچک ترکیب کند.

## مرحله 1 — مدل ورودی
برنامه چند نمره از کاربر دریافت می‌کند. فقط عدد بین 0 تا 20 معتبر است. فرمان `done` ورود را تمام می‌کند.

## مرحله 2 — توابع
حداقل این توابع ساخته شوند:
- `read_scores()` دریافت و اعتبارسنجی
- `calculate_average(scores)` محاسبه میانگین
- `get_status(average)` تعیین وضعیت
- `print_report(scores)` نمایش گزارش

## مرحله 3 — گزارش
گزارش باید تعداد نمرات، میانگین با دو رقم اعشار، کمترین، بیشترین و وضعیت را نمایش دهد.

## مرحله 4 — مدیریت خطا
ورودی غیرعددی نباید برنامه را متوقف کند. List خالی باید به شکل مشخص مدیریت شود.

## مرحله 5 — تست دستی
سناریوها:
1. نمرات عادی
2. فقط یک نمره
3. مقدار منفی
4. مقدار بیشتر از 20
5. متن نامعتبر
6. پایان بدون ثبت نمره

## معیار قبولی
- منطق به تابع تقسیم شده باشد.
- نام متغیرها واضح باشد.
- ورودی نامعتبر crash ایجاد نکند.
- محاسبات درست باشند.
- کد تکراری غیرضروری وجود نداشته باشد.

## توسعه اختیاری
ذخیره گزارش در فایل JSON و نمایش تاریخچه گزارش‌ها.
