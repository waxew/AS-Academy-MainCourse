## سیاست انتخاب منبع
1. برای تعریف API و رفتار مرورگر، مرجع رسمی اولویت دارد.
2. برای توضیح فارسی، چند منبع فارسی مقایسه می‌شوند.
3. اطلاعات قدیمی یا وابسته به نسخه قبل از ورود به درس با مستند رسمی کنترل می‌شود.
4. لینک منبع جایگزین محتوای آموزشی داخل Academy نیست؛ درس باید قابل استفاده مستقل باشد.
5. منابع پولی فقط به‌عنوان مطالعه بیشتر معرفی می‌شوند و محتوای دارای حق نشر بازنشر نمی‌شود.
