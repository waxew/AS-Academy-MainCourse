# AS Academy — Frontend

دوره جامع «طراحی و توسعه وب‌سایت / Frontend» برای Academy Learn.

این بسته بر اساس قراردادهای `AS-Academy-MainCourse` و `AS-Academy-MainUi` طراحی شده و محتوای آموزشی را از UI جدا نگه می‌دارد. MainUi فقط با `courseId=frontend` این بسته را بارگذاری می‌کند.

## دامنه دوره
HTML، CSS، Responsive Design، Sass، Bootstrap، Tailwind CSS، JavaScript، DOM، Event، Fetch/API، Async/Await، Storage، TypeScript، Web Components، PWA، Service Worker، State Management، Testing، Performance، Accessibility، Security، Tooling و پروژه‌های واقعی.

## الگوی آموزش
`مفهوم → توضیح فارسی → مثال → تمرین → خطاهای رایج → نکته حرفه‌ای → آزمون → مینی‌پروژه → پروژه نهایی`

## سطح‌ها
مبانی، مقدماتی، متوسط، پیشرفته، تخصصی و پروژه‌محور.

منابع فارسی و رسمی در `course/SOURCES.md` ثبت می‌شوند و متن درس‌ها به‌صورت مستقل و آموزشی تدوین می‌شود.
