# برنامه جامع دوره دیتابیس و ذخیره‌سازی ابری

## مبانی
ابر و BaaS، Managed PostgreSQL، Object Storage و S3، Bucket/Object/Key، CDN، Authentication/Authorization، Token/Session، Least Privilege و Shared Responsibility.

## مقدماتی
Supabase، Firebase، Appwrite، PocketBase، CRUD، اتصال Web/Android، Auth، Storage Bucket، metadata فایل، upload/download و طراحی object key.

## پیشرفته
PostgreSQL RLS و Policy، Realtime و sync، Edge Functions، webhook و idempotency، Signed/Presigned URL، S3 Compatible Storage، Cloudflare R2، MinIO، Multipart Upload، Resumable Upload، checksum، CDN، Cache-Control و ETag.

## تخصصی
Multi-tenancy، ACL و sharing model، secret management، audit و hardening، performance/scale/cost، lifecycle، backup/PITR، RPO/RTO، migration و disaster recovery، logs/metrics/SLO و پروژه نهایی فضای ذخیره‌سازی اشتراکی امن.

## خروجی یادگیری
دانشجو باید بتواند سرویس مناسب را انتخاب کند، دیتابیس و storage را امن متصل کند، دسترسی را در سمت سرور enforce کند، فایل بزرگ را قابل ادامه آپلود کند، لینک اشتراک زمان‌دار بسازد و یک معماری Production-like برای سرویس فایل طراحی کند.
