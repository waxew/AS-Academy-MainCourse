# منابع و مراجع دوره

این فایل فهرست منابع برای مطالعه تکمیلی و راستی‌آزمایی فنی است. متن درس‌ها تألیفی است و کپی مستقیم از منابع نیست.

## روش استفاده از منابع
برای مباحثی که سرویس ابری مرتب تغییر می‌کند، مستندات رسمی منبع نهایی هستند. آموزش فارسی برای توضیح و مسیر یادگیری استفاده می‌شود و syntax، محدودیت، قیمت و رفتار امنیتی باید با مستندات رسمی همان نسخه کنترل شود.
