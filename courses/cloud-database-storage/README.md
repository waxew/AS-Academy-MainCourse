# دیتابیس و ذخیره‌سازی ابری

شناسه پایدار دوره: `cloud-database-storage`

این بسته آموزشی برای AS Academy و بر اساس قرارداد `AS-Academy-MainCourse`/`AS-Academy-MainUi` ساخته شده است. محتوا به زبان فارسی و در چهار سطح «مبانی، مقدماتی، پیشرفته، تخصصی» ارائه می‌شود و موضوعات Supabase، Firebase، Appwrite، PocketBase، PostgreSQL مدیریت‌شده، Auth، RLS، Realtime، Edge Functions، Storage، Signed URL، S3، Cloudflare R2، MinIO، CDN، Multipart/Resumable Upload و اشتراک‌گذاری امن را پوشش می‌دهد.

مسیر محتوای قابل مصرف توسط برنامه: `courses/cloud-database-storage/course/`

منابع مرجع و پیوندهای آموزشی در `course/SOURCES.md` نگهداری می‌شوند. متن درس‌ها تألیفی و فارسی است و از منابع به‌صورت مرجع برای صحت فنی استفاده می‌کند.
