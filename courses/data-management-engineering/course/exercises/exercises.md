# تمرین‌های عملی

1. یک ماتریس RPO/RTO برای سه سرویس بانکی، فروشگاهی و وبلاگ طراحی کنید.
2. Runbook بازیابی PostgreSQL پس از حذف اشتباه جدول بنویسید.
3. Migration بدون downtime برای تغییر نوع یک ستون حجیم طراحی کنید.
4. مدل Role و Privilege برای اپلیکیشن سه‌لایه بسازید.
5. ظرفیت Connection Pool را برای 12 instance محاسبه و محدودیت‌ها را توضیح دهید.
6. سناریوی Failover و جلوگیری از Split Brain طراحی کنید.
7. برای جدول 5 میلیارد رکوردی Partition Key پیشنهاد دهید.
8. یک داشبورد Monitoring شامل حداقل 12 Metric تعریف کنید.
9. Star Schema فروش را با FactSales و Dimensionهای اصلی طراحی کنید.
10. Pipeline idempotent برای ورود فایل روزانه طراحی کنید.
11. Topic/Partition strategy برای 50 هزار event در ثانیه طراحی کنید.
12. Failure Mode Analysis برای Capstone انجام دهید.
