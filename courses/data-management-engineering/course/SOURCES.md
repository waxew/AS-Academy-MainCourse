# منابع تحقیق و توسعه محتوا

محتوا به‌صورت تألیفی و فارسی، با استفاده از چند گروه منبع تدوین شده است؛ متن منابع عیناً کپی نشده است.

## منابع فارسی
- CodeFolio — آموزش PostgreSQL: Query، Indexing، Replication، HA، Backup/PITR و Monitoring.
- مدرسه مهندسی داده سپهرام — مطالب و کارگاه‌های فارسی درباره PostgreSQL، Partitioning/FDW، Airflow، Kafka، Spark، MinIO، ClickHouse و معماری Bronze/Silver/Gold.
- BINP — دوره معماری پلتفرم داده: Data Warehouse، ETL/ELT، Kafka، CDC، Data Lake/Lakehouse و معماری سازمانی.

## منابع مرجع تکمیلی
- PostgreSQL Documentation
- Apache Kafka Documentation
- Apache Airflow Documentation
- Apache Spark Documentation
- dbt Documentation

هدف این فایل ثبت provenance آموزشی است؛ درس‌ها بازنویسی، ساختاربندی و بومی‌سازی شده‌اند.
