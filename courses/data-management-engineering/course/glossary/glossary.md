# واژه‌نامه

- RPO: بیشترین میزان داده قابل‌قبول برای از دست رفتن.
- RTO: بیشترین زمان قابل‌قبول برای بازیابی سرویس.
- PITR: بازیابی دیتابیس تا یک نقطه زمانی مشخص.
- WAL: لاگ پیش‌نوشت تراکنش در PostgreSQL.
- RBAC: کنترل دسترسی مبتنی بر نقش.
- Audit Log: لاگ قابل ممیزی عملیات حساس.
- Replication Lag: فاصله زمانی/داده‌ای Replica از Primary.
- Failover: انتقال سرویس به Node سالم.
- Split Brain: وجود همزمان بیش از یک Primary ناسازگار.
- Partitioning: تقسیم جدول داخل یک سامانه دیتابیس.
- Sharding: تقسیم داده بین چند Node مستقل.
- ETL/ELT: الگوهای انتقال و تبدیل داده.
- CDC: دریافت تغییرات داده از لاگ تراکنش.
- Data Warehouse: مخزن تحلیلی ساخت‌یافته.
- Data Lake: مخزن گسترده داده خام/نیمه‌ساخت‌یافته.
- Lakehouse: ترکیب قابلیت‌های Lake و Warehouse.
- Kafka Offset: موقعیت یک پیام در Partition.
- Watermark: مرز مدیریت eventهای دیررس در Streaming.
- Idempotency: اجرای تکراری بدون ایجاد اثر اضافه یا خرابی داده.
