# پروژه‌ها

## پروژه 1 — Disaster Recovery Lab
PostgreSQL را با Full Backup، WAL Archive و PITR پیکربندی کنید؛ حذف عمدی داده را شبیه‌سازی و RTO واقعی را ثبت کنید.

## پروژه 2 — HA Database
Primary/Replica، Health Check، Failover Runbook، Connection Pool و Monitoring طراحی کنید.

## پروژه 3 — Enterprise Warehouse
برای فروشگاه، Star Schema و SCD Type 2 بسازید و ETL روزانه با تست کیفیت داده طراحی کنید.

## پروژه 4 — Streaming Pipeline
رویدادهای سفارش را به Kafka ارسال کنید، Consumer Group بسازید، Deduplication و Dead Letter را پیاده‌سازی و Lag را مانیتور کنید.

## Capstone — Modern Data Platform
OLTP + CDC + Kafka + Object Storage + Spark/dbt + Warehouse + BI را به‌صورت معماری کامل طراحی کنید. مستندات باید شامل SLA/SLO، امنیت، Backup، HA، Cost، Data Quality، Lineage و Incident Runbook باشد.
