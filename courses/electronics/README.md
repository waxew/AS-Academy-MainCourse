# تخصصی الکترونیک — AS Academy

این پوشه مرجع محتوای دوره جامع «تخصصی الکترونیک» در MainCourse است.

مسیر از مبانی برق و قطعات، ابزارهای اندازه‌گیری و لحیم‌کاری شروع می‌شود و تا الکترونیک آنالوگ/دیجیتال، میکروکنترلر و Embedded، پروتکل‌های ارتباطی، PCB، IoT، رباتیک، کنترل صنعتی، الکترونیک قدرت، RF، FPGA، تعمیرات و طراحی محصول ادامه دارد.

## قرارداد اجرا
- شناسه دوره: `electronics`
- محتوای قابل نمایش برنامه: `course/electronics`
- RTL و زبان اصلی: فارسی
- سطح‌بندی: مبانی، مقدماتی، متوسط، پیشرفته، تخصصی، پروژه‌محور
- منبع حقیقت محتوا: AS-Academy-MainCourse
- رابط نمایش: AS-Academy-MainUi / AcademyFolderCourseHost

## ایمنی
آموزش برق شهر، منابع تغذیه متصل به شبکه، ولتاژ بالا، اینورتر، UPS، باتری‌های پرتوان و الکترونیک قدرت صرفاً به‌صورت نظری/شبیه‌سازی و با تأکید بر محیط آزمایشگاهی کنترل‌شده، تجهیزات حفاظت فردی و نظارت فرد متخصص ارائه می‌شود.
