# منابع و سیاست تدوین دوره الکترونیک

محتوای AS Academy ترجمه مستقیم یا کپی هیچ منبعی نیست؛ درس‌ها به فارسی و با ساختار مستقل تألیف می‌شوند. منابع زیر برای کنترل دامنه سرفصل، اصطلاحات، مشخصات فنی و به‌روزبودن مسیر استفاده می‌شوند.

## منابع رسمی مرجع
- Arduino Documentation — docs.arduino.cc
- Arduino Learn / Built-in Examples — docs.arduino.cc/built-in-examples
- Espressif ESP-IDF Programming Guide — docs.espressif.com/projects/esp-idf
- STM32 Documentation & STM32Cube — st.com
- Microchip Developer Help / AVR & PIC documentation — microchip.com
- Raspberry Pi Documentation — raspberrypi.com/documentation
- FreeRTOS Documentation — freertos.org
- KiCad Documentation — docs.kicad.org
- Bluetooth SIG — bluetooth.com
- LoRa Alliance — lora-alliance.org
- OASIS MQTT specification — mqtt.org / oasis-open.org
- CAN in Automation — can-cia.org
- USB-IF — usb.org
- NXP/Nordic/TI/Analog Devices application notes و datasheetهای قطعات به‌عنوان منابع مهندسی تکمیلی

## منابع آموزشی فارسی برای تطبیق اصطلاح و نیاز مخاطب
در جست‌وجوی وب فارسی، آموزش‌های الکترونیک و میکروکنترلر در مراجع آموزشی ایرانی مانند فرادرس، مکتب‌خونه، دانشجویار، توسینسو و وب‌سایت‌های تخصصی رباتیک/الکترونیک بررسی می‌شوند. از این منابع صرفاً برای شناسایی ترتیب رایج آموزش، اصطلاحات فارسی و شکاف‌های محتوایی استفاده می‌شود و متن دوره مستقل تألیف می‌شود.

## روش کنترل کیفیت
1. موضوع ابتدا با مستندات رسمی سازنده یا استاندارد تطبیق داده می‌شود.
2. توضیح فارسی از صفر و با مثال مستقل نوشته می‌شود.
3. مقادیر وابسته به قطعه به Datasheet ارجاع مفهومی داده می‌شوند و به‌عنوان قانون عمومی بیان نمی‌شوند.
4. مباحث دارای ریسک الکتریکی با Warning/Important مشخص می‌شوند.
5. هر فصل باید در نسخه‌های تکمیلی شامل درس، مثال، تمرین، آزمون و در صورت مناسب پروژه باشد.

## محدودیت ایمنی
این دوره راهنمای عملی کار بدون نظارت با برق شهر یا ولتاژ بالا نیست. مباحث SMPS آفلاین، اینورتر، UPS، باتری‌های پرتوان، RF توان بالا و تجهیزات پزشکی صرفاً در محدوده طراحی مهندسی، تحلیل، شبیه‌سازی و الزامات ایمنی مطرح می‌شوند مگر اینکه محیط آزمایشگاهی کنترل‌شده و مربی متخصص وجود داشته باشد.
