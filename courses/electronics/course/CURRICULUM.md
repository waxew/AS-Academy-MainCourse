# برنامه جامع تخصصی الکترونیک

## هدف
ساخت مسیر فارسی، مرحله‌ای و پروژه‌محور برای رساندن هنرجوی صفر تا سطح طراحی، ساخت، برنامه‌نویسی، تست و عیب‌یابی سیستم الکترونیکی.

## مبانی
ایمنی و ESD؛ واحدها و SI؛ بار الکتریکی؛ ولتاژ، جریان، مقاومت؛ قانون اهم؛ توان و انرژی؛ DC/AC؛ فرکانس، دوره، فاز و RMS؛ سری/موازی؛ قوانین Kirchhoff؛ تحلیل Node/Mesh؛ نقشه‌خوانی و نمادها؛ مقاومت/خازن/سلف؛ دیود و LED؛ BJT و MOSFET؛ رله، فیوز، رگولاتور و IC؛ Breadboard؛ Datasheet؛ مولتی‌متر، اسیلوسکوپ، منبع آزمایشگاهی و Logic Analyzer.

## مقدماتی
لحیم THT/SMD و Rework؛ تحلیل RC/RL/RLC؛ فیلترهای Passive/Active؛ تقویت‌کننده؛ Bias؛ Op-Amp؛ Comparator؛ Feedback؛ 555؛ جبر بولی؛ گیت؛ Flip-Flop؛ Counter/Register؛ ADC/DAC؛ انواع سنسور؛ LCD/OLED؛ DC Motor، Stepper، Servo و Driver؛ منابع خطی و اصول باتری/شارژ.

## متوسط
C برای Embedded؛ Bitwise؛ Pointer و حافظه؛ معماری MCU؛ GPIO؛ Interrupt؛ Timer/PWM؛ ADC؛ Arduino؛ AVR؛ PIC؛ STM32؛ ESP8266/ESP32؛ Arduino Core و ESP-IDF؛ Raspberry Pi؛ MicroPython؛ Embedded Linux مقدماتی؛ UART/I2C/SPI/1-Wire؛ RS232/RS485؛ Modbus؛ CAN؛ USB؛ Ethernet؛ Wi-Fi؛ BLE؛ Zigbee؛ LoRa/LPWAN؛ RFID/NFC؛ GPS؛ MQTT.

## پیشرفته
FreeRTOS و طراحی Concurrent؛ Queue/Semaphore/Mutex؛ ISR؛ Memory Management؛ Debug با SWD/JTAG؛ Bootloader و OTA؛ KiCad؛ شماتیک و PCB چندلایه؛ Stack-up؛ Ground/Power Plane؛ Return Current؛ Decoupling؛ Signal Integrity و Power Integrity؛ EMI/EMC؛ ESD/Surge Protection؛ RF Layout؛ Gerber و DFM؛ مونتاژ SMD؛ Thermal Design؛ SMPS و مبدل‌های Buck/Boost؛ BMS؛ Control/Feedback/PID؛ Instrumentation؛ Sampling و DSP.

## تخصصی
IoT و خانه هوشمند؛ امنیت Device؛ Edge AI/TinyML؛ رباتیک و مکاترونیک؛ PLC/HMI/SCADA؛ پروتکل‌های صنعتی؛ الکترونیک قدرت؛ خورشیدی، UPS و اینورتر؛ RF و آنتن؛ FPGA و Verilog/VHDL؛ SoC؛ ARM/RISC-V؛ الکترونیک خودرو و CAN؛ آشنایی مهندسی تجهیزات پزشکی؛ سیستم امنیتی و CCTV؛ تعمیر برد؛ طراحی محصول؛ BOM؛ Component Sourcing؛ DFM/DFA/DFT؛ Jig/Fixture؛ Functional Test؛ کنترل کیفیت؛ Reliability؛ مدیریت چرخه عمر قطعه؛ آشنایی با CE/FCC و انطباق محصول.

3. دماسنج دیجیتال با نمایشگر
4. کنترل موتور با PWM

## سیاست ایمنی
فعالیت عملی روی برق شهر، ولتاژ بالا، منابع بدون ایزولاسیون، باتری پرتوان، UPS/اینورتر و بخش‌های قدرت برای آموزش خودآموز تعریف نمی‌شود. این موضوعات با شبیه‌سازی، تحلیل شماتیک و توضیح نظری آموزش داده می‌شوند و اجرای عملی فقط در آزمایشگاه مجهز و زیر نظر متخصص مجاز است.
