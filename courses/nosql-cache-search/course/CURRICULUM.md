# برنامه جامع NoSQL، Cache و Search

این Course Package برای AS Academy بر اساس معماری MainCourse/MainUi طراحی شده و از مبانی تا سطح تخصصی Production را پوشش می‌دهد.

## مبانی
NoSQL چیست، چرایی پیدایش، تفاوت با RDBMS، Document/Key-Value/Wide-Column/Graph/Time-Series، CAP، ACID و BASE، Strong/Eventual Consistency، Replication، Partitioning، Sharding، Horizontal Scaling، Consistent Hashing و Polyglot Persistence.

## مقدماتی
### MongoDB
نصب، mongosh، Database/Collection/Document، BSON، CRUD، Operators، Projection، Sort/Pagination، Array/Embedded Document، Embedding vs Referencing، Schema Validation، Index/Compound/Unique/Partial/TTL، Aggregation Pipeline، $lookup، Transaction، Auth، Replica Set، Sharding، Backup/Restore، Atlas و Performance.

### Redis و Valkey
String، Hash، List، Set، Sorted Set، Bitmap، HyperLogLog، Streams، TTL، Expiration، Cache، Session، Rate Limiting، Distributed Lock، Pub/Sub، Queue، Leaderboard، RDB/AOF، Eviction، Transaction، Lua، Replication، Sentinel، Cluster و Monitoring.

### Firebase
Realtime Database: JSON Tree، Read/Write، Listener، Offline، Query، Auth، Security Rules، Transaction، Atomic Write و Presence. Firestore: Collection/Document، Query، Index، Subcollection، Listener، Offline Persistence، Batch، Transaction، Rules، Pagination و Data Modeling.

## پیشرفته
Cassandra با CQL و Query-driven Modeling؛ DynamoDB با GSI/LSI، Capacity و Single-table؛ Neo4j و Cypher؛ Elasticsearch/OpenSearch با Analysis، Inverted Index، Query DSL، Aggregation و Relevance؛ Time-Series و InfluxDB با Retention، Downsampling و Telemetry.

## تخصصی
Cache Engineering، Search Engineering، جست‌وجوی فارسی، Fuzzy/Autocomplete/Facet، Semantic Search، Vector Search، Hybrid Search، Embedding و RAG؛ معماری Multi-Region، HA/DR، Security، Monitoring، Profiling، Benchmark و Capacity Planning.

## پروژه‌ها
Chat بلادرنگ، Backend فروشگاه، Session/Cache، Rate Limiter، Leaderboard، Search فروشگاه و فارسی، Recommendation/Fraud Graph، IoT Monitoring و Capstone چنددیتابیسی SaaS.

## روش آموزشی هر فصل
هر مبحث باید شامل توضیح مفهومی فارسی، مثال، سناریوی واقعی، اشتباه رایج، تمرین، Quiz و در فصل‌های مناسب پروژه عملی باشد. اصطلاحات انگلیسی استاندارد در کنار معادل فارسی حفظ می‌شوند تا دانشجو بتواند مستندات رسمی را نیز مطالعه کند.
