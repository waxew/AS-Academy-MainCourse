# منابع دوره NoSQL، Cache و Search

متن درس‌ها تألیفی و فارسی است. منابع فارسی برای شیوه آموزش و منابع رسمی برای راستی‌آزمایی فنی و تغییرات نسخه استفاده می‌شوند.

## منابع فارسی بررسی‌شده
فرادرس، مکتب‌خونه، راکت، تاپ‌لرن و مقالات فنی فارسی مرتبط با MongoDB، Redis، Firebase، Elasticsearch و پایگاه داده. مطالب وبلاگی فقط پس از تطبیق با مستندات رسمی مبنا قرار می‌گیرند.

## منابع رسمی مرجع
MongoDB Documentation؛ Redis Documentation؛ Valkey Documentation؛ Firebase Realtime Database و Cloud Firestore Documentation؛ Apache Cassandra Documentation؛ AWS DynamoDB Developer Guide؛ Neo4j Documentation؛ Elastic Elasticsearch Reference؛ OpenSearch Documentation؛ InfluxData Documentation.

## سیاست کنترل کیفیت
1. API، Syntax، محدودیت و قابلیت نسخه‌ای با Documentation رسمی کنترل می‌شود.
2. متن منابع فارسی یا رسمی عیناً کپی نمی‌شود.
3. هر مفهوم با توضیح فارسی، مثال، سناریوی واقعی، خطای رایج و تمرین تکمیل می‌شود.
4. Cloud Pricing و قابلیت‌های Managed Service در نسخه‌های بعدی دوباره بازبینی می‌شوند.
5. Search فارسی باید Unicode، Normalization حروف فارسی/عربی، نیم‌فاصله، Tokenization، Analyzer، Synonym و Typo tolerance را پوشش دهد.
