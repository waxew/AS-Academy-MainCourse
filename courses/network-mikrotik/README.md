# تخصصی شبکه و MikroTik

این پوشه منبع اصلی محتوای آموزشی مسیر «تخصصی شبکه و MikroTik» در AS Academy است.

- Source of Truth: `AS-Academy-MainCourse`
- UI Host: `AS-Academy-MainUi` / `AcademyFolderCourseHost`
- سطوح: مبانی، مقدماتی، پیشرفته، تخصصی
- مبنا: RouterOS v7 و مفاهیم استاندارد شبکه
- ساختار: درس، لابراتوار، تمرین، آزمون، پروژه و واژه‌نامه

هدف دوره این است که هنرجو از صفر شبکه تا طراحی، پیاده‌سازی، ایمن‌سازی و عیب‌یابی شبکه‌های واقعی MikroTik، سازمانی، ISP و WISP پیش برود. محتوای گواهی‌نامه‌ای با مسیر رسمی MikroTik هم‌راستا است، اما این دوره مدرک رسمی MikroTik صادر نمی‌کند.
