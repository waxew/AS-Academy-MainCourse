# تمرین‌های SQL — بسته ۱

1. جدول `customers` را با کلید اصلی، نام اجباری، ایمیل یکتا و تاریخ ایجاد بسازید.
2. جدول `orders` را با Foreign Key به مشتری طراحی کنید.
3. پنج مشتری و ده سفارش درج کنید.
4. مشتریانی را پیدا کنید که مجموع خریدشان بیشتر از یک مقدار مشخص است.
5. مشتریان بدون سفارش را با LEFT JOIN استخراج کنید.
6. فروش ماهانه را با GROUP BY گزارش کنید.
7. برای هر مشتری آخرین سفارش را با Window Function پیدا کنید.
8. Query شماره 4 را با Subquery و سپس CTE بازنویسی و مقایسه کنید.
9. برای Query پرتکرار یک Index پیشنهادی ارائه دهید و دلیل ترتیب ستون‌ها را توضیح دهید.
10. یک UPDATE و DELETE را داخل Transaction اجرا کنید و سناریوی ROLLBACK بسازید.
11. نمونه کد آسیب‌پذیر به SQL Injection را به Parameterized Query تبدیل کنید.
12. با EXPLAIN/Execution Plan مشخص کنید Query شما Scan انجام می‌دهد یا از Index بهره می‌گیرد.

معیار ارزیابی: صحت نتیجه، خوانایی Query، رعایت NULL، جلوگیری از Cartesian Product، استفاده صحیح از Transaction و توضیح Performance.
