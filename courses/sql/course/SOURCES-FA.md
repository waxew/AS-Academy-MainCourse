# منابع و سیاست تولید محتوای فارسی SQL

محتوای AS Academy بازنویسی و تألیف آموزشی مستقل است و متن منابع دیگر عیناً کپی نمی‌شود.

## منابع فارسی برای تکمیل و تطبیق مسیر یادگیری
- فرادرس: دوره‌ها و مطالب فارسی SQL، پایگاه داده و SQL Server
- تاپ‌لرن: آموزش‌های فارسی SQL/SQL Server و پایگاه داده
- راکت: مطالب فارسی توسعه وب و دیتابیس مرتبط با SQL
- کوئرا: تمرین و محتوای آموزشی برنامه‌نویسی/دیتابیس در بخش‌های مرتبط
- مکتب‌خونه: دوره‌های فارسی پایگاه داده و SQL در صورت وجود دوره مرتبط

## مراجع فنی مرجع برای راستی‌آزمایی
- PostgreSQL Documentation
- MySQL Reference Manual
- Microsoft Learn / SQL Server Documentation
- SQLite Documentation
- OWASP SQL Injection Prevention Cheat Sheet

## روش استفاده
1. موضوعات و ترتیب آموزشی از چند منبع مقایسه می‌شوند.
2. تعریف فنی با مستندات رسمی DBMS راستی‌آزمایی می‌شود.
3. متن درس به فارسی و با مثال مستقل AS Academy نوشته می‌شود.
4. تفاوت Dialectها در درس مشخص می‌شود و Syntax یک DBMS به‌عنوان SQL عمومی معرفی نمی‌شود.
5. مطالب امنیتی و Performance با مثال قابل آزمایش ارائه می‌شوند.

این فهرست برای attribution و کنترل کیفیت نگهداری می‌شود؛ لینک یا محتوای شخص ثالث بخشی از Course Package آفلاین نیست مگر مجوز آن روشن باشد.
