# SQL — AS Academy

این پوشه بسته آموزشی جامع SQL برای AS Academy است و بر اساس معماری MainCourse/MainUi ساخته شده است.

مسیر یادگیری از مبانی تا تخصصی: مفاهیم SQL، طراحی و ساخت دیتابیس و جدول، CRUD، فیلتر و مرتب‌سازی، Join، Group By، Subquery، View، Index، Function، Procedure، Trigger، Transaction، Window Function، Full-Text Search، بهینه‌سازی Query، Execution Plan، امنیت و جلوگیری از SQL Injection.

محتوا فارسی، RTL، پروژه‌محور و مستقل از DBMS خاص طراحی شده و تفاوت‌های PostgreSQL، MySQL/MariaDB، SQL Server و SQLite در بخش‌های لازم توضیح داده می‌شود.
