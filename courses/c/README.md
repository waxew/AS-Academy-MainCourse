# C Course Package

این پوشه منبع واحد محتوای آموزشی زبان C در AS Academy است.

- Source of Truth: `AS-Academy-MainCourse/courses/c/course`
- Course app/repository: `AS-Academy-C`
- Shared UI: `AS-Academy-MainUi`
- Shared engine/runtime: `AS-Academy-Core`

تمام درس‌ها، فصل‌ها، تمرین‌ها، Quizها، پروژه‌ها، Capstone، Glossary و metadata آموزشی C از اینجا مدیریت می‌شوند.
Course App محتوا را هنگام Build از این مسیر دریافت می‌کند و نباید fork مستقل محتوا داشته باشد.
