# JavaScript Course Package

این پوشه منبع واحد محتوای آموزشی JavaScript در AS Academy است.

- Source of Truth: `AS-Academy-MainCourse/courses/javascript/course`
- App shell: `AS-Academy-JavaScript`
- Shared UI: `AS-Academy-MainUi`
- Shared engine: `AS-Academy-Core`

از زمان این مهاجرت، درس، فصل، تمرین، Quiz، آزمون، پروژه، Capstone، Glossary و Branding دوره JavaScript باید در همین پوشه تغییر کند و App دوره فقط آن را بسته‌بندی/مصرف کند.
