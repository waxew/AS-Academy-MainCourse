# PHP Course

این مسیر، منبع اصلی محتوای PHP در معماری جدید AS Academy است.

## سطوح اصلی
1. مبانی (`foundation`)
2. مقدماتی (`beginner`)
3. پیشرفته (`advanced`)
4. تخصصی (`specialist`)

محتوای موجود در `AS-Academy-php/app/src/main/assets/course/php` باید به `courses/php/course` مهاجرت شود. پس از تکمیل migration، تغییرات محتوایی PHP فقط در این مسیر انجام می‌شوند و اپ PHP صرفاً بسته منتشرشده MainCourse را مصرف می‌کند.

## هدف کیفیت
PHP باید یک مرجع کامل باشد، نه مجموعه‌ای از چند درس کوتاه. درس‌های بزرگ باید به واحدهای آموزشی واقعی و مستقل شکسته شوند و هر مبحث با توضیح، مثال، نکته، خطای رایج، تمرین، آزمون و پروژه مناسب پوشش داده شود.
