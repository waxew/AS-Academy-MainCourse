# طراحی و توسعه وب‌سایت / مبانی وب

Course Package مستقل «مبانی وب» برای AS Academy.

این دوره مطابق `AS-Academy-MainCourse` ساخته شده و UI، RTL، Navigation، Search، Progress و Quiz Engine را از `AS-Academy-Core` و `AS-Academy-MainUi` مصرف می‌کند.

## سطوح
- Foundation — مبانی
- Beginner — مقدماتی
- Advanced — پیشرفته
- Specialist — تخصصی

## محدوده آموزشی
اینترنت و وب، Website/Web App/Mobile App، Client/Server، URL/IP/Port، Domain/DNS، Hosting/Server/VPS/Cloud، HTTP/HTTPS، Request/Response، Status Codes، Browser Rendering، DevTools، Frontend/Backend/Full Stack، API/REST/JSON، Cookie/Session/Web Storage، Cache/CDN، VS Code و Terminal، Git/GitHub، RTL و فارسی، Unicode/UTF-8، Accessibility، Security، TLS، SEO، Performance/Core Web Vitals، Deploy و اتصال Domain.

## الگوی آموزشی
هر درس شامل هدف، توضیح مفصل، مثال واقعی، نکات مهم، اشتباهات رایج، تمرین و ارتباط با Quiz/Project است.

محتوا تألیفی و بازنویسی‌شده است؛ منابع فارسی و مراجع رسمی در `course/references.json` برای مطالعه تکمیلی و صحت‌سنجی ثبت شده‌اند.
