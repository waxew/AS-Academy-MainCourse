# Backend وب — AS Academy

این پوشه Course Package مسیر «طراحی و توسعه وب‌سایت / Backend وب» است.

محتوا مطابق قرارداد `AS-Academy-MainCourse` در چهار سطح ثابت زیر سازمان‌دهی شده است:

1. `foundation` — مبانی
2. `beginner` — مقدماتی
3. `advanced` — پیشرفته
4. `specialist` — تخصصی

## دامنه دوره

Node.js، Express، NestJS، PHP/Laravel، Python/Django، FastAPI، Java/Spring Boot، Kotlin/Ktor، C#/ASP.NET Core، Go، REST API، GraphQL، WebSocket، Authentication/Authorization، JWT/Session، Upload، Payment، Email، SMS، Notification، Queue، Cache، Admin Panel، Multi-Tenant و SaaS.

در نسخه تکمیل‌شده این مسیر، موضوعات مکمل دیتابیس و ORM، Validation، Error Handling، Logging، Testing، OpenAPI/Swagger، OWASP، Rate Limiting، Docker، CI/CD، Observability، معماری نرم‌افزار و Performance نیز پوشش داده شده‌اند.

پوسته و Design System از `AS-Academy-MainUi` و منطق مشترک برنامه از `AS-Academy-Core` تأمین می‌شود؛ این پوشه فقط داده و محتوای آموزشی را نگه می‌دارد.
