# برنامه جامع Backend وب

## مبانی — foundation
1. Backend و زیرساخت وب: Client/Server، HTTP/HTTPS، Request/Response، Header/Body، Status Code، JSON، Cookie/Session/Token، DNS، Port، Environment، Git و Postman.
2. مهندسی Backend: ساختار پروژه، Package Manager، Config/Secret، Logging/Debugging، Error Handling، Validation، SQL/NoSQL، ORM، Migration و Transaction.
3. Node.js: Runtime، Event Loop، Modules، npm/pnpm، FS، Stream، Buffer، Promise، Async/Await و HTTP.
4. PHP: Composer، OOP، Namespace، Autoload، PDO و Request/Response.
5. Python: venv، Package، Type Hint، Async، WSGI و ASGI.
6. Java/Kotlin/C#/Go: JVM/JDK، Maven/Gradle، Coroutines، .NET DI، Go Modules، goroutine و net/http.

## مقدماتی — beginner
7. Express: Routing، Middleware، Controller، Validation، Error Middleware، CRUD، Database و Auth.
8. NestJS: Module، Controller، Provider، DI، DTO، Pipe، Guard، Interceptor، Filter، ORM و Swagger.
9. Laravel: Routing، Controller، Middleware، Eloquent، Migration، Seeder، Factory، Validation، API Resource و Sanctum.
10. Django/DRF: Project/App، URL/View، Model/ORM، Migration، Admin، Serializer، ViewSet و Permission.
11. FastAPI: Path/Query/Body، Pydantic، DI، SQLAlchemy/SQLModel، Async، OpenAPI و OAuth2/JWT.
12. Spring Boot: Controller/Service/Repository، DI، JPA، Validation، Exception Handling و Security.
13. Ktor: Routing، Plugin، Serialization، Database/Exposed، Authentication و Coroutines.
14. ASP.NET Core: Minimal/Controller API، DI، Configuration، EF Core، Middleware، Identity و JWT.
15. Go Web: net/http، Router، Middleware، Gin/Fiber، database/sql، Context و Graceful Shutdown.
16. REST API: Resource Modeling، URI، Status Code، Pagination/Filter/Sort/Search، Versioning، Error Contract و OpenAPI.

## پیشرفته — advanced
17. Authentication/Authorization: Hashing، Session، JWT Access/Refresh، Rotation/Revocation، OAuth2/OIDC، RBAC/ABAC، MFA.
18. Security: OWASP/API Security، Injection، XSS/CSRF/CORS/SSRF، Rate Limit، Secure Headers، Secrets، Upload Security، Audit.
19. GraphQL: Schema، Query/Mutation، Resolver، Validation، Auth، Pagination، DataLoader، Subscription.
20. WebSocket/Realtime: Upgrade، Room/Channel، Presence، Reconnect، Heartbeat، Socket.IO، Pub/Sub.
21. Upload/Object Storage: Multipart، validation، S3-compatible، Signed URL، Image Processing، Resumable Upload.
22. Payment: Flow، Callback، Verify، Idempotency، Webhook، Invoice/Refund، Adapter درگاه.
23. Email/SMS/Notification: SMTP، Template، OTP، Provider Adapter، Push، Retry و Delivery Status.
24. Queue: Producer/Consumer، Redis Queue، RabbitMQ، Retry/Backoff، DLQ، Cron، Idempotent Worker.
25. Cache: Cache Aside، Redis/Valkey، TTL، Eviction، Invalidation، Distributed Cache.
26. Testing: Unit، Integration، E2E، Mock، Contract، Load/Stress و Security Test.
27. Admin Panel: Admin Auth، Role/Permission، CRUD، Dashboard، Search/Filter/Export، Audit، Soft Delete.
28. Docker/Deployment: Dockerfile، Compose، Reverse Proxy، TLS، CI/CD، Migration، Health Check.

## تخصصی — specialist
29. Architecture: Layered، Clean، Hexagonal، DDD، Repository/Service، Modular Monolith، Event-driven.
30. Performance/Scale: Profiling، Pool، Index/Query Optimization، N+1، Horizontal Scaling، Load Balancer، Stateless، CDN.
31. Observability/Reliability: Structured Logs، Metrics، Tracing/OpenTelemetry، SLI/SLO، Health، Backup/DR.
32. Microservices: Boundary، Sync/Async، Gateway، Broker، Saga، Distributed Transactions، Discovery و Anti-patternها.
33. Multi-Tenant/SaaS: Shared/Separate Schema، DB per Tenant، Tenant Resolution، Isolation، Plan/Quota، Feature Flag، Metering/Billing.
34. پروژه‌ها: فروشگاه API، نوبت‌دهی Realtime، LMS Backend، Admin چندنقشی، SaaS چندمستاجری و Capstone Production-ready.
