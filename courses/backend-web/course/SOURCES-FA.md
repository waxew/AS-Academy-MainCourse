# فهرست منابع فارسی برای تکمیل Backend وب

این فایل «منبع پژوهش و ارجاع» است؛ متن دوره باید تألیفی/بازنویسی‌شده باشد و محتوای منابع بدون مجوز کپی نشود.

## منابع آموزشی فارسی شناسایی‌شده
- راکت (roocket.ir): دوره‌ها و مقالات Node.js، Express، NestJS، Laravel و موضوعات Backend.
- فرادرس (faradars.org): آموزش‌های فارسی Node.js، PHP/Laravel، Python/Django، Java/Spring، ASP.NET Core، پایگاه داده و مباحث مهندسی نرم‌افزار.
- Quera College (quera.org/college): دوره‌ها و تمرین‌های برنامه‌نویسی/Backend و مسیرهای پروژه‌محور فارسی.

## روش استفاده در AS Academy
1. برای هر فناوری، مفاهیم و ترتیب آموزشی منابع فارسی بررسی می‌شود.
2. صحت فنی با Documentation رسمی همان فناوری کنترل می‌شود.
3. درس نهایی به زبان فارسی و با مثال مستقل AS Academy نوشته می‌شود.
4. برای موضوعات سریع‌التغییر مثل نسخه فریم‌ورک، Security و Deployment، مستند رسمی مرجع نهایی صحت است.
5. مثال‌ها باید قابل اجرا، امن و متناسب با نسخه ثبت‌شده در metadata درس باشند.

## مراجع رسمی کنترل صحت
Node.js Docs، Express Docs، NestJS Docs، PHP Docs، Laravel Docs، Python Docs، Django Docs، FastAPI Docs، Spring Boot/Spring Security Docs، Ktor Docs، ASP.NET Core Docs، Go Docs، OpenAPI، GraphQL، OWASP، Redis/Valkey، RabbitMQ، PostgreSQL و Docker Docs.
