# پروژه‌های Backend وب

## پروژه ۱ — API دفترچه کارها | مبانی
CRUD، Validation، Error Contract، SQLite/PostgreSQL و تست Endpointها.

## پروژه ۲ — فروشگاه | مقدماتی
User/Product/Category/Cart/Order، Authentication، Role، Pagination، Search، Transaction و مستندات OpenAPI.

## پروژه ۳ — سامانه نوبت‌دهی | پیشرفته
کاربر، پرسنل، تقویم، ظرفیت، رزرو، WebSocket، Email/SMS Notification، Queue، Redis Cache، Audit Log و Admin API.

## پروژه ۴ — سرویس فایل | پیشرفته
Multipart، Object Storage سازگار با S3، Signed URL، Permission، محدودیت حجم، پردازش Background و ثبت metadata.

## پروژه ۵ — Payment Service | پیشرفته
Payment Intent داخلی، Redirect/Callback، Verify، Idempotency Key، Webhook، Refund، Ledger ساده و Adapter Provider.

## پروژه ۶ — SaaS چندمستاجری | تخصصی
Tenant، User Membership، RBAC، Plan، Feature، Quota، Usage Metering، Billing، Tenant Isolation، Super Admin و Audit.

## Capstone — Production Backend
یک سامانه واقعی با PostgreSQL، Redis/Valkey، Queue، REST، GraphQL، Realtime، Object Storage، Authentication، RBAC، Rate Limiting، Test Suite، Docker، CI/CD، Health Check، Structured Logging، Metrics/Tracing و Backup Strategy.

### معیارهای نهایی
- API Contract مستند
- Migration قابل تکرار
- Secret خارج از Source Code
- تست مسیرهای بحرانی
- کنترل دسترسی Server-side
- Idempotency برای عملیات حساس
- Error Handling پایدار
- Observability پایه
- مستند Deployment و Rollback
- Threat Model خلاصه
