# منابع و مراجع دوره

این فایل برای کنترل صحت فنی، به‌روزرسانی دوره و مطالعه تکمیلی است. متن درس‌ها تألیفی است و از منابع زیر کپی مستقیم نشده است.

## منابع رسمی اصلی
- MDN Web Docs — HTTP, HTTPS, Web Security, Performance
- OWASP — OWASP Top 10 (نسخه 2025)، Cheat Sheet Series و Web Security Testing Guide
- Nginx Documentation — Beginner's Guide، Reverse Proxy، SSL/TLS، Load Balancing
- Apache HTTP Server Documentation — Virtual Hosts، SSL/TLS، Modules و Security
- Let's Encrypt / Certbot Documentation — HTTPS و تمدید گواهی
- Linux man pages و Ubuntu Server Documentation — کاربران، Permission، systemd، SSH و Firewall
- Docker Docs — Dockerfile، Images، Containers، Volumes، Networks، Compose و Production
- GitHub Docs — Actions، Environments، Secrets، Deployments، Security Hardening
- Cloudflare Learning Center & Docs — DNS، CDN، Cache، SSL/TLS، WAF، DDoS و Rules
- web.dev — Core Web Vitals، LCP، INP، CLS، Performance و Lighthouse
- Google Search Central — Technical SEO، Crawling، Indexing، Sitemap، robots.txt، Canonical و Structured Data
- Google Analytics Help/Developers — GA4، Events، Measurement و Debug
- Google Search Console Help — Indexing و Search Performance
- IETF/RFC references — HTTP، TLS، DNS و Cache semantics در مباحث تخصصی

## منابع فارسی برای مطالعه تکمیلی و تطبیق اصطلاحات
در جستجوی فارسی دوره، آموزش‌ها و مقالات مرتبط با Linux Server، Nginx/Apache، SSL، Docker، GitHub Actions، Cloudflare، CDN، امنیت OWASP، Core Web Vitals، SEO، Google Analytics، Backup و Monitoring بررسی می‌شوند. به دلیل تغییر سریع سرویس‌ها، صحت فرمان‌ها و تنظیمات نهایی همیشه با مستند رسمی همان محصول تطبیق داده می‌شود.

منابع فارسی رایج قابل بررسی در به‌روزرسانی‌ها شامل مستندات/وبلاگ‌های ارائه‌دهندگان زیرساخت ایرانی و وب‌سایت‌های آموزشی فارسی در حوزه Linux، DevOps، Docker، SEO و مدیریت سرور هستند. هیچ منبع فارسی به‌تنهایی Source of Truth فنی دوره نیست.

## سیاست به‌روزرسانی
- امنیت: تطبیق دوره با آخرین OWASP Top 10 و advisories مهم.
- Performance: تطبیق با تعریف جاری Core Web Vitals در web.dev.
- Analytics/SEO: تطبیق با مستندات جاری Google.
- Cloud/Docker/CI: بررسی تغییر Syntax و قابلیت‌های Deprecated قبل از هر Release محتوایی.
- دستورات عملیاتی مخرب یا تغییرات Production باید همراه Backup/Rollback و هشدار مناسب آموزش داده شوند.
