# انتشار و نگهداری سایت

این پوشه Course Package مستقل مسیر «طراحی و توسعه وب‌سایت → انتشار و نگهداری سایت» است.

هدف دوره این است که هنرجو از مرحله انتخاب دامنه و هاست، DNS و Linux Server تا استقرار Production، Docker، CI/CD، امنیت، مانیتورینگ، Backup، Performance، SEO، Analytics، Privacy و نگهداری بلندمدت یک وب‌سایت واقعی را یاد بگیرد.

## سطوح
- مبانی (foundation)
- مقدماتی (beginner)
- پیشرفته (advanced)
- تخصصی (specialist)

## ساختار
محتوا مطابق قرارداد AS-Academy-MainCourse در `course/` نگهداری می‌شود و توسط AS-Academy-MainUi نمایش داده می‌شود. منطق Progress، Search، Quiz، Exercise و Project در AS-Academy-Core قرار دارد.

## سیاست محتوا
متن درس‌ها تألیفی و فارسی است. منابع فارسی و مستندات رسمی برای کنترل صحت فنی در `course/sources.md` ثبت شده‌اند. متن منابع دیگر مستقیماً کپی نشده است.
