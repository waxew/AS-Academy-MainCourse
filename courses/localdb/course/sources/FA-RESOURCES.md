# منابع فارسی و مراجع تکمیلی

محتوای کورس تالیفی است؛ منابع فقط برای مطالعه تکمیلی و راستی‌آزمایی فنی فهرست می‌شوند.

- Nouri Academy / DataStore: https://nouri.academy/product/android-programming-course
- Magic Codes Farsi / SQLite Android: https://www.youtube.com/watch?v=7p04FLSnfjA
- Mehdi Haghgoo / SQLite Android: https://www.youtube.com/watch?v=r-W6EBmb_wg

## فارسی Web

## مراجع رسمی
- Android Offline-first: https://developer.android.com/topic/architecture/data-layer/offline-first
- SQLCipher Android: https://github.com/sqlcipher/sqlcipher-android
- Apple Core Data: https://developer.apple.com/documentation/coredata/
- Apple SwiftData/Core Data adoption: https://developer.apple.com/documentation/coredata/adopting-swiftdata-for-a-core-data-app

منابع فارسی رایگان در اولویت‌اند. لینک‌های خراب/قدیمی در نسخه‌های بعدی جایگزین می‌شوند و برای رفتار نسخه‌محور API، مستند رسمی مرجع نهایی است.
