# مبانی
Persistence یعنی داده پس از بسته‌شدن برنامه یا صفحه قابل بازیابی باشد. RAM موقتی است؛ ماندگاری با File، Key-Value Store یا Database ایجاد می‌شود.

فایل برای تصویر/PDF/JSON بزرگ؛ Key-Value برای تنظیمات کوچک؛ Database برای Query، Relation و Transaction مناسب است. انتخاب باید بر اساس حجم، Query، حساسیت، Migration و Sync انجام شود.

Cache قابل بازسازی است اما Source of Truth منبع قابل اتکای وضعیت است. در Offline-First معمولاً دیتابیس محلی منبع UI است.

تمرین: برای تنظیم زبان، صد هزار تراکنش، عکس پروفایل، سبد خرید موقت و پیش‌نویس آفلاین ابزار مناسب انتخاب کنید و دلیل بنویسید.
