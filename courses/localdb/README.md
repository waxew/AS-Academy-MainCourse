# LocalDB Course

منبع واحد محتوای دوره «دیتابیس داخلی اندروید» در معماری جدید AS Academy.

- Runtime/Engine: `AS-Academy-Core`
- Shared UI/UX: `AS-Academy-MainUi`
- Course content: همین مسیر در `AS-Academy-MainCourse`
- Thin host app: `-AS-Academy-LocalDB`

پس از این مهاجرت، تغییرات جدید درس‌ها، فصل‌ها، Quizها، تمرین‌ها و پروژه‌ها باید ابتدا در MainCourse انجام شوند.
